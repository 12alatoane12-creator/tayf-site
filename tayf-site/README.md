# طيف | TAYF — مختبر الفيزياء والكيمياء

نسخة أولية تفاعلية تعمل في المتصفح، بواجهة عربية RTL. تتضمن:

- صفحة دخول بسيطة بخياري الفيزياء والكيمياء.
- مختبر دوائر DC مع تحرير قيم مصدر الجهد والمقاومات، عرض تيار/هبوط جهد/قدرة وفق نموذج مقاومات على التوالي، ورسالة حل مجهول مع خطوات.
- مكتبة عناصر مرئية؛ المتسعات والملفات والدايودات وأجهزة القياس ظاهرة للاستكشاف لكن ليست كلها مدعومة في الحساب العددي.
- مختبر كيمياء بمجموعة تعليمية محدودة: تعادل HCl/NaOH، ترسيب AgCl من AgNO3/NaCl، وحاسبة التركيز/المولات/الحجم. الخلطات غير المدعومة تُعرض على أنها غير مدعومة، لا كأنها غير متفاعلة.
- جدول دوري مختصر للاستكشاف، وعاء متحرك بصريًا، سجل تجارب محفوظ محليًا، فتح/حذف/تصدير JSON.
- تصميم متجاوب ومظهر فاتح/داكن واحترام إعداد تقليل الحركة.

## التشغيل

1. فك ضغط الملف.
2. افتح `index.html` في متصفح حديث، أو شغّل خادم ملفات ثابتًا من مجلد المشروع، مثل:

   ```bash
   python -m http.server 8000
   ```

   ثم افتح `http://localhost:8000`.

3. انتقل إلى مختبر الفيزياء أو الكيمياء واحفظ تجربة لتجربتها ضمن «تجاربي».

## مهم: حدود النسخة الحالية

- لا يوجد تسجيل حسابات أو خادم خلفي أو حفظ سحابي. «تجاربي» تستخدم `localStorage` في المتصفح والجهاز الحالي فقط.
- رسم الدائرة حاليًا بصري، والحل العددي يستخدم افتراض نموذج توالي لمصدر جهد مثالي ومقاومات؛ لا يستنتج التوصيلات العامة من الرسم. أداة الأسلاك ما زالت واجهة تمهيدية.
- لا يوجد تعرف آلي شامل على الرسم الحر؛ زر إضافة المكونات يضيف رمزًا واضحًا إلى مساحة الرسم.
- التفاعلات الكيميائية مدعومة فقط في الحالات المبرمجة صراحةً، مع افتراضات معلنة. لا تمثل قاعدة بيانات كيميائية شاملة ولا تتنبأ بكل التفاعلات.
- الجدول الدوري في هذه النسخة مختصر، ولا يحتوي خواص تفصيلية لكل عنصر.
- المؤثرات البصرية ليست قياسًا فيزيائيًا أو كيميائيًا. لا تستخدم الموقع لاتخاذ قرارات مختبرية أو سلامة واقعية.

## ما يلزم للوصول إلى المنتج الكامل

1. إضافة خلفية آمنة للمستخدمين والجلسات وقاعدة بيانات ومزامنة وتحديد صلاحيات.
2. بناء محرر توصيلات قائم على عقد وأسلاك حقيقية، ثم دمج محلل دوائر عام (MNA) أو محرك موثوق، مع اختبارات مرجعية.
3. توسيع المحاكاة الزمنية للمكثفات والملفات والدايودات مع نماذج مُتحقَّق منها.
4. بناء مخطط بيانات كيميائية موثق للتوازن والذوبانية والحركية والحرارة والأنشطة الكيميائية، مع توثيق المصدر وعدم اليقين.
5. اختبارات استخدام وإتاحة وأداء وأمان ومراجعة علمية من مختصين.

## بنية الملفات

- `index.html` هيكل الواجهة.
- `styles.css` التصميم المتجاوب.
- `app.js` تفاعلات الواجهة والنماذج التعليمية والتخزين المحلي.
