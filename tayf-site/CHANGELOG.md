# سجل التغييرات

## 0.2.0 — أساس TypeScript والإصلاحات العلمية

- نقل نقطة التشغيل إلى Vite + TypeScript وتقسيم الشيفرة إلى محرك الدوائر والكيمياء، تحليل الوحدات، البيانات، سجل الحالة، والتخزين.
- استبدال جمع المقاومات المتسلسلة الثابت بحل MNA مبني على أطراف وأسلاك حقيقية؛ إضافة تشخيصات الدائرة المفتوحة والقصر والقيم غير الصالحة والعقد العائمة.
- إضافة رسم سلك فعلي بالنقر على طرفين، اختيار عنصر ثم وضعه، تحريكًا متوافقًا مع حجم SVG، تحريكًا بلوحة المفاتيح، وتراجع/إعادة.
- إضافة `parseQuantity` للجهد والتيار والمقاومة والسعة، مع عرض القيمة المحولة ورسائل تحقق.
- إضافة نافذة قبل إدخال المادة لتحديد الكمية والتركيز، مع دعم حجم المحلول أو المولات؛ عُطّل تحويل الكتلة حتى توثيق الكتل المولية.
- حساب كيمياء التعادل من المولات والحجم الكلي الفعلي، إزالة قص pH إلى 0–14، إضافة حساب التخفيف بحجم عينة ابتدائي، وتصحيح موازنة المولات والحجوم عند تكرار الإضافة وتعديل التركيز/الحجم.
- إيقاف الفقاعات والألوان والراسب غير المدعوم، مع فصل لون بطاقة المادة عن لون المحلول.
- تعقيم القيم الديناميكية قبل عرضها، وحماية التخزين المحلي، وإضافة إصدار مخطط واستيراد JSON بتحقق صارم.
- إضافة كتالوج مواد JSON ومخططه، ومخطط تصدير المشروع، والتحقق الصارم من مفاتيح ملفات الاستيراد.
- إضافة اختبارات Vitest وPlaywright وCI وملفات التخطيط والقرارات.

## حدود التحقق

- تم تشغيل `tsc --noEmit` و`tsc -p tsconfig.smoke.json` واختبارات Node smoke بنجاح.
- لم يتم تشغيل `npm run build` أو Vitest أو ESLint أو Playwright E2E في هذه البيئة؛ الاعتماديات غير مثبتة، ومحاولة تشغيل Playwright تعذرت بسبب قيود التنقل في المتصفح داخل بيئة التنفيذ. انظر `TESTS.md`.
